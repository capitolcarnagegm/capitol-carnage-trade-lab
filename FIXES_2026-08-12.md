# Critical Fixes — 2026-08-12

## Root causes found

1. **Game Day schedule empty**
   - `handleCurrentGames` filtered OUT every game with `state === "pre"`
   - In August almost all games are scheduled (pre), so the schedule was always empty

2. **Free agents missing**
   - Only Fantrax page 1 was requested (`pageNumber: 1`)
   - Fantrax caps results per page well below the full waiver pool

3. **Rosters not syncing**
   - `/league-data` required `workspaceId`
   - If missing, returned "League not found" and the UI stayed a shell
   - No fallback to the user's first linked league

4. **Repeated info**
   - Chat + UI kept restating instructions instead of answering with live data
   - Caused by empty context (no roster / FA / schedule payload)

## Deploy required

These fixes are in GitHub. Cloudflare must redeploy the worker:

```bash
npx wrangler deploy
```

From the repo root (uses `wrangler.toml` → `cloudflare-router.js` → `cloudflare-worker.js`).

If auto-deploy from GitHub is connected, push to main should trigger it.
